# Last Chair Standing

A top-down boss-rush prototype where each boss is built on the feeling of a children's party game. Boss 1, Maestro Grumble, plays musical chairs: when the music stops, race his Ushers for too few chairs.

**Play:** https://winecoolermike.github.io/last-chair-standing/

Controls: WASD move, mouse aim, click or J swing, Space dash, right-click or K shove.
